# Project Rules — Lab 02

# Scope

- Complete Exercise 1, followed by Exercise 2 and Exercise 3.
- Finish and verify each sub-task before moving on to the next.

# Workflow

- Break down the work into independent sub-tasks.
- Contract-First approach: Define TypeScript interfaces, function inputs/outputs, and invariants before beginning implementation.
- Each task should result in only a single function or module.
- Verify via tests and developer tools (DevTools).
- Track tasks and the actual verification process in the `TASK_DECOMPOSITION.md` file.
- Never mark a requirement as "met" without having performed actual testing.
  Keep commits separate and maintain the correct sequence. Stage only those files that belong to the current milestone.

# Audit Evidence

- Record verification steps only after they have been completed. Record AI errors only when supported by actual evidence.
- Do not fabricate errors, screenshots, test results, or audit findings.

# Homework Rules

- Complete Homework 1, Homework 2, and Homework 3 separately.
- Use a separate AI conversation and prompt link for each homework.
- Break each homework into small tasks in TASK_DECOMPOSITION.md.
- Define the necessary contracts before implementing each feature.
- Ask AI to help with one independent task at a time.
- Read and understand AI-generated code before using it.
- Test each task and record the actual verification results.
- Use const and let instead of var. Avoid implicit global variables.
- Use keydown with e.key or e.code instead of keypress or keyCode.
- Do not use inline event handlers. Use event delegation where appropriate.
- Use safe DOM APIs and textContent for user input instead of raw innerHTML.
- Use semantic HTML and follow the accessibility requirements of each homework.
- Make separate atomic commits for distinct tasks. Do not combine different homework assignments in one commit.
- Use Conventional Commits. Homework 3 must have at least eight separate commits.
- Record real AI errors, evidence, and fixes in AI_FAILURE_AUDIT.md. Do not fabricate findings.
