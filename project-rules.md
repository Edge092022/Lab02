# Project Rules — Lab 02
# Scope
- Complete Exercise 1, followed by Exercise 2 and Exercise 3.
- Finish and verify each sub-task before moving on to the next.
# Workflow
- Break down the work into independent sub-tasks.
- Contract-First approach: Define TypeScript interfaces, function inputs/outputs, and invariants before beginning implementation.
- Each task should result in only a single function or module.
- Verify via tests and developer tools (DevTools).
- Track tasks and the actual verification process in the `TASK_DECOMPOSITION.md` file.
- Never mark a requirement as "met" without having performed actual testing.
Keep commits separate and maintain the correct sequence. Stage only those files that belong to the current milestone.
# Audit Evidence
- Record verification steps only after they have been completed. Record AI errors only when supported by actual evidence.
- Do not fabricate errors, screenshots, test results, or audit findings.
